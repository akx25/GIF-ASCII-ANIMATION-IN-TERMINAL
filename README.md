# GIF-ASCII-ANIMATION-IN-TERMINAL
Simple Python script.





How to install: 

First install Python if you haven't yet (https://www.python.org/)

When Python is installed, copy & paste this to Terminal/PowerShell:

git clone https://github.com/akx25/GIF-ASCII-ANIMATION-IN-TERMINAL.git
cd GIF-ASCII-ANIMATION-IN-TERMINAL
py -m pip install pillow
py NixOSascii.py
